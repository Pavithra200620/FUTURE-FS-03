# ☕ Sip Serenity - Tea Delivery App

A full stack tea delivery web application built as my first project to understand real-world web development flow (frontend + backend + database integration).

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Atlas)  
- **Email Service:** Nodemailer  

---

## ✨ Features

- 🛒 Add to Cart with quantity control  
- 💳 Checkout system with order confirmation  
- 📦 Order storage in MongoDB  
- 📧 Email notification on order placement  
- 📩 Contact form with email support  
- 📱 Fully responsive UI for mobile & desktop  

---

## 🚀 How to Run Locally
 
### Backend setup
cd sivabackend
npm install
npm start

### Frontend Setup

Just open the file in browser:

sivafrontend/index.html
